# Decisions

Architecture decisions, one file each, in the order made. 0001 to 0019 were inherited from oaken-mail and keep their
numbers and their older bullet format (`- Status:`, `- Date:`); new ones use MADR. Numbering continues from 0019 (0020 is held for the
one ADR 0019 points at).

Template: MADR (Markdown Architectural Decision Records, <https://adr.github.io/madr/>), copied from this folder's
[`TEMPLATE.md`](TEMPLATE.md), chosen 2026-11-22.

| Setting | Value |
|---|---|
| Owner | Drew Foulks |
| Naming | `NNNN-short-title.md` |
| Status words | proposed, accepted, rejected, deprecated, superseded |

Only the owner ratifies. An accepted decision's text is never rewritten: change it with an amendment section or a
new decision that supersedes it. The website's [decision index](../../docs/adr/index.html) is generated from this folder and reads both formats.
